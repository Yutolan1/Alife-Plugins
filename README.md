# Alife-Plugins

我的 Alife 插件合集：收录自己**魔改**与**原创**的 Alife 插件源码与发布包，持续更新。

## 目录结构
- `Tsumi.DeskPet/` —— Live2D 桌宠（魔改自官方 Alife.Function.DeskPet）
- `Wv.plugin.LifeLedger/` —— 生活账本（原创）
- `Wv.plugin.Memory/` —— 分层持久记忆（魔改自官方 Alife.Function.Memory）
- `publish/` —— 插件市场发布包（zip + 注册 json + 发布说明）

## 插件清单
| 插件 | 来源 | 一句话说明 |
|---|---|---|
| Tsumi.DeskPet | 官方魔改 | 智能鼠标穿透（人形掩码/区域/永久区）、手势与摸头交互、模型热切换、水印自动隐藏、缩放偏移持久化 |
| Wv.plugin.LifeLedger | 原创 | 生活账本 |
| Wv.plugin.Memory | 官方魔改 | 分层情景记忆：分级折叠/总上下文预算/语义活文档/身份锚与底色演化/记忆可信度与证据核查/22 条本地评估/5 驱力欲望状态机 |
| Wv.plugin.DeskPet | 官方魔改（旧版） | 4.3.0 市场包（见 publish/，已被 Tsumi.DeskPet 取代） |

## 约定
- 源码以各插件目录为准；`publish/` 只放可安装的市场包与发布说明。
- 每个插件一个目录，目录名 = 插件 Id。
